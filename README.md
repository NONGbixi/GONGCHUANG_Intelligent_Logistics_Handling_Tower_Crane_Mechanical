# 2027工创赛智梭速运升降台

面向智能物流搬运任务的升降台机械资料，包含 SolidWorks 零件模型、装配体、紧固件清单和三物料搬运动画。

- 原文：[《工创赛2025-塔吊方案机械开源（2分15秒）》西安理工大学工程训练中心](https://blog.csdn.net/louisaerdusai/article/details/150106890)

## 打开装配体

解压或完整克隆仓库后，用 SolidWorks 打开：

`模型/智梭_2027升降台总_铝条支架_标准紧固件.SLDASM`

请保留整个“模型”文件夹及其中的相对位置。发布副本的 CAD 文件统一添加“智梭_”前缀，方便与本机已有的同名源模型区分。

- 发布副本中的旧上下文关联及导入链接处理，见“文档”内记录。

## 清单与动画说明

两份 Excel 清单为原样复制，分别用于紧固件明细与商家采购参考。采购前请结合当前装配、加工工艺和实际库存复核；本次没有重写清单数量。

动画为现有方案演示素材，预览图由指定发布总装导出。它们不代替最终装配的尺寸、运动干涉和加工验证。
